    About This Project

    Introduction

    Weather data is collected every hour, so it is too large to read by eye. This project uses R to clean and summarise a weather dataset (hourly records) and a web dashboard to present the results clearly.

    Objectives

    • Clean the dataset (duplicates, impossible values, dates).
    • Calculate mean, median, mode, spread and correlations.
    • Find trends and seasonal patterns.
    • Show the real results in an interactive dashboard.

    Technologies Used

    • R (readr, dplyr, lubridate, ggplot2, jsonlite) – analysis
    • HTML – page structure
    • CSS – styling and responsive layout
    • JavaScript – loads the JSON files and builds tables
    • Chart.js – interactive charts

    Methodology

    1. Load weather.csv in R.
    2. Check missing values and duplicates, then clean.
    3. Calculate statistics, correlations and trends.
    4. Export results to summary.json and chart_data.json.
    5. JavaScript reads those files and draws the dashboard.
